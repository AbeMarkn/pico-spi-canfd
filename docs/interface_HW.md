# ハードウェアインターフェース

文書版: `0.1.0`。設計IDの定義は[Design.md](Design.md)。出典は[REF-001／002／005／006／011](references.md)。配線はユーザー指定、電気設定は現物確認を条件とする設計。実環境はP3開放・120 Ω抵抗非実装、相手2台＋自分の計3台、CAN配線長30 cm以内。

INTのリセット既定はpush-pull。open-drainが常に固定された端子とは説明しない。Pico入力を先に用意し、IOCON設定とプルアップ先を確認してからIRQを有効にする。外付け抵抗値は提案であり実装済みではない。

CLKはSPIクロックの入力端子ではない。Pico側から駆動しない。INT0は送信完了を直接表す専用線と解釈せず、INT1と併せた補助IRQの追加は必要性が判明した場合にだけ再検討する。

## 2. P2・P3・CAN端子

- **P2**: 開放。P1-10の3.3 VとP1-12の5 Vを両方供給する指定。短絡箇所がどの電源ネットを接続するかは回路図・導通で確認する（DESN-HW-002、OPEN-005）。
- **P3**: バス端点の終端担当時だけ有効。ユーザー回答により、現在はP3開放かつ120 Ω抵抗非実装と確定（DESN-HW-005、OPEN-004）。自分を含む3台・CAN配線30 cm以内の構成で、既存の二端終端を使う。
- **G**: CAN側基準GND。Pico側GNDとの内部接続／絶縁の有無を確認する。保護接地と同義にしない。
- **H／L**: CANH／CANL。双方向差動信号。dominant時はH>L、recessive時は差動が小さい。GPIO用プルアップは付けない。端子の見た目の左右ではなく印字で接続する。
- **ATA6563 STBY**: ICではHighがstandby、Lowがnormal。P1へ専用STBYとして露出しているとは確認できない。INT0経由や基板固定配線かを未決事項として記録する。

## 4. 現物確認と測定方法（OPEN-005、未実施）

ユーザー指定により、現物の電気確認は保留し、後日オシロスコープとテスターで行う。保留を検証完了とは扱わず、本節の測定手順を維持する。

実装は、発振周波数・STBY接続・電気設定を機器config.pyへ分離して進められる。最新のユーザー指示により接続済み構成で通信試験を実施したが、電気条件の確定には下記の確認が必要。未確認を「20 MHz確認済み」「STBY固定Low」として実装へ埋め込まない。本節は測定方法の説明だけで、通電や試験を実施した記録ではない。

### 4.1 必要な器具と測定時の接続

無給電の導通・抵抗と直流電圧にはテスターを使う。発振周波数にはオシロスコープまたは対応帯域の周波数計、SPI／CAN波形にはオシロスコープと適合するデコーダを使う。周波数を測れないテスターだけで20 MHzを確定しない。

導通・抵抗測定は全3台の電源とUSBを外し、残留電圧がないことを確認して行う。基板内部の導通はモジュールをPico・CAN配線から外して測る。ICの1番マークを起点に番号を照合し、隣接ピンをプローブで短絡させない。オシロスコープのGNDは回路GNDへ接続し、CANH／CANLへGNDクリップを接続しない。CAN差動は適合する差動プローブ、または両チャネルを共通GND基準にしてCH1−CH2で測る。

### 4.2 まず確認する電源経路と信号の導通

1. **GNDと電源**: テスターの抵抗レンジで、P1-8／11とMCP2518FDの7番（VSS）、ATA6563の2番（GND）を照合する。P1-10（3V3）からMCP2518FDの14番（VDD）とATA6563の5番（VIO）、P1-12（5V）からATA6563の3番（VCC）までの経路を確認する。保護ダイオード等を介す場合は単純な導通音だけで判定せず、回路・抵抗値・測定極性を記録する。
2. **P2**: 開放を目視し、両パッドがどの電源ネットへ接続するかを追う。3.3 Vと5 Vを短絡する状態では接続しない。各電源–GND間の低抵抗が充電後も続くなら原因を確認する。半導体とコンデンサがあるので、抵抗が有限というだけで故障とも正常とも断定しない。
3. **INT0–STBY**: P1-4（INT0、MCP2518FD 9番）とATA6563の8番（STBY）、STBY–GND、STBY–VIOをそれぞれ抵抗レンジで測る。直接接続ならリード抵抗に近い値、抵抗経由ならその抵抗値を記録する。直接または抵抗経由でINT0につながっている場合、GP21を弱プルアップする未使用入力案を適用せず、STBY制御の設定を確定する。STBYがGND固定ならソフトによるStandby停止には使えない。
4. **INTとnCSのプルアップ先**: P1-9（INT）とP1-1（nCS）につながる抵抗を目視・導通で追い、抵抗の反対側が3.3 Vか5 Vかを確かめる。INT–3V3の抵抗値だけで外付け抵抗の値を断定しない。5 Vへの経路があればPicoの信号線を接続する前に処置を設計する。既設の3.3 Vプルアップがあれば追加抵抗との並列値を考慮する。

この段階で必要な記録は、電源経路、P2の接続先、STBYの接続先、INT／nCSのプルアップ先と抵抗値。導通が曖昧なら「不明」とし、回路図または基板パターンの追跡で補う。根拠: REF-002 表1-1、REF-005 表1-2。部品の標準ピン配置と、この基板の実配線を区別する。

### 4.3 給電後の電圧と発振周波数

電源経路・短絡の確認を終え、給電元の余裕と電流制限を確認してから行う。最初はCANバスとPicoの信号線を外し、必要な電源とGNDだけを接続する。

- テスターの黒をGND、赤をP1-10／P1-12と各IC電源ピンへ当てる。MCP2518FD VDDとATA6563 VIOは3.3 V系、ATA6563 VCCは5 V系であることを確認する。ATA6563の参照電気条件はVCC 4.5〜5.5 V、VIO 2.8〜5.5 Vだが、本接続のVIO目標は3.3 V。Picoへ戻る信号を5 V系にしない。コネクタ側5 Vが正常でも保護素子後のVCCを別に測る。
- STBYはLowで通常動作、HighでStandbyとなる。電源投入直後と初期化後を分けて記録する。未接続のSTBYには内部プルアップがあるため、導通音がないことを固定Lowの証拠にしない。
- **コードを書かずに行える周波数の初期確認**: モジュールの電源投入リセットが成立し、その後SPIで設定されていない条件では、MCP2518FDはPLL無効・CLKO分周10・SOF無効が初期値。P1-2（CLK）を10:1高インピーダンスプローブで観測する。20 MHzなら約2 MHz（周期500 ns）、40 MHzなら約4 MHz（250 ns）が目安になる。これは初期値と出力経路が成立した場合の算出値。既存プログラムがレジスタを変えている場合、この換算を使わない。
- 波形がない場合は水晶不良と即断せず、CLKの導通、電源、既存プログラム、Sleep／SOF設定を確認する。水晶のOSC1／OSC2へ通常プローブを直接当てて発振を乱さない。初期動作後にOSC・IOCONを読戻し、既知の分周設定とCLK実測を照合して機器config.pyの発振値を確定する。OSCRDYやDEVIDだけでは周波数を測定したことにならない。

電源電流を測る場合は、電源を切ってから対象電源線へ電流計を直列に入れる。電流レンジのプローブを電源–GND間へ並列に当てない。待機時と実送受信時を分けて測り、採用給電元と各部品の許容条件に照合する。根拠: REF-002 OSC／IOCON／§5、REF-005 電気表。実部品へ適用する改訂・許容差は記録に残す。

### 4.4 3台・30 cm以内のCAN配線と終端

全3台を無給電にし、実運用どおりH／Lを接続した状態でH–L間を測る。両端に120 Ωが一つずつなら計算上は約60 Ω。約120 Ωなら終端一つ、約40 Ωなら三つの並列を疑って配置を追うが、他の回路や抵抗誤差もあるため抵抗値だけで位置・個数を断定しない。自モジュールのP3は開放、120 Ωは非実装のままとする。

N947参照文書はCAN0側とCAN1側に各120 Ωを記載している。自ノードをその間または短い分岐で接続し、主配線・分岐長と終端位置を記録する。3台という台数と30 cmという短さだけでは二端終端の確認を省略しない。N947文書の過去測定値は今回の3台構成の実測値に転記しない。根拠: REF-012、REF-014。

### 4.5 初期動作後に確認する事項

初期化コードができてから、SPI mode 0・初期1 MHz／動作4 MHz、INTのHigh電圧・Low応答・立上り、500 kbit/s／2 Mbit/sとBRS、TDCV・エラーカウンタ、停止までの時間を確認する。TDCはテスターの直流測定では確定できない。4 IDの実データ波形とエラー状態で調整・評価する。

OPEN-005のうちコード作成前にすべての負荷試験を済ませる必要はない。4.2と4.3の情報で実機用初期設定を決め、4.5は完成した初期化・通信処理の確認として行う。結果はTEST-DESN-201、TEST-DESN-101、TEST-DESN-102、TEST-DESN-108等へ実施後に記録する。今回は日時・実測値・合否を記入しない。

## 5. ソフトウェアからの確認記録（電気測定とは別）

2026-09-13〜14、MCP2518FDを20 MHz・PLLなし・CLKO÷10として初期化し、GP20のPIOカウントでCLKO約1,998,889 Hzを観測した。20 MHz設定を支持する補助観測であり、オシロによる電圧・デューティ・ジッタ・水晶精度の測定ではない。SPI設定は初期1 MHz、運転4 MHz、mode 0。CANの500 k／2 M設定でN947のFD64フレームを受信し、NormalモードのTEF送信完了を確認した。TDC値は設定の読戻しであり、アナログ波形の最適化確認ではない。

GP26は入力＋弱プルアップ、総合INTのみIRQを使用。GP20／21／22は入力とし未知のSTBY経路を能動駆動しない。GP0〜4・25はPWM統合用の予約を維持。P2電源経路、INTプルアップ先、STBY実配線、H–L抵抗・電圧・保護性能は測定未実施。結果と配置SHAは[実施結果](test/results/TEST-SPEC-DESN_result_001.md)に記録する。
