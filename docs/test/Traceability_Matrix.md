## 3. テスト → 定義ファイルと結果

全Test IDの定義は次のファイルにあり、各行から関連SPEC／DESNへ逆参照できる。同じTest IDを別試験へ再利用しない。

- [仕様正常系](Test_for_Specification.md): TEST-SPEC-001〜009、101〜110、201〜202。
- [仕様正常系以外](Test_for_Specification_non_normal.md): TEST-SPEC-021〜025、121〜127、221〜223。
- [設計正常系](Test_for_Design.md): TEST-DESN-001〜014、101〜108、201。
- [設計正常系以外](Test_for_Design_non_normal.md): TEST-DESN-021〜027、121〜126、221。

[第1回結果](results/TEST-SPEC-DESN_result_001.md)に実装・79件の実機なし試験・実CAN2試験・内部ループバック・120秒試験の条件と証跡を記録した。計画のTest IDに対して全条件を満たさない場合は部分検証とし、未達や未実施をPassへ置き換えない。仕様／設計の結果テンプレートは未実施用として維持する。

## 4. 対応できない項目の扱い

全SPECには設計と仕様テスト、全DESNには設計テストの計画がある。PWM同居試験はOPEN-012、電気・性能試験はOPEN-005・015、N947接続はOPEN-018が実施の前提。OPEN-006・009の目標と方式は採用済み。対応計画があることと、実施可能・検証済みであることを区別する。

## 2026-09-14 受入条件追補

ユーザーの明示指示により、SPEC-NF-002の周期精度については現状実測性能をREADMEに記載する条件で許容する。元の評価目標・実測Failは履歴として維持し、目標達成とは扱わない。優先順位をGUI実操作、再接続・通信断・ログ保存へ変更する。GUIの自動ロジック試験と実操作確認は区別する。早期時間満了、誤送信、停止不良、データ不一致などの機能不具合は、この性能許容に含めない。追加評価はTEST-SPEC-DESN_result_002.mdを参照する。
